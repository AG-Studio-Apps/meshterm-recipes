meshTerm host recipes

The install, fix and start commands meshTerm shows for a server, as signed data, so a command that a Linux distribution broke can be fixed without an app update. meshTerm only uses this file after its signature verifies against the keys built into the app.

  • recipes.json and its signature recipes.json.minisig
  • recipes.schema.json
  • Public keys: primary, emergency

Source and how to propose a change: github.com/AG-Studio-Apps/meshterm-recipes.
